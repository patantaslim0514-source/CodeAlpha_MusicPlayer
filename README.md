# 🎵 Melodia – Music Player

A modern, responsive music player built using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

Melodia provides a simple and interactive music-listening experience with a playlist, playback controls, volume adjustment and a stylish dark-themed interface.

## 🌐 Live Demo

[🎧 View Melodia Music Player](https://patantaslim0514-source.github.io/CodeAlpha_MusicPlayer/)

## ✨ Features

* 🎵 **Play & Pause:** Play and pause songs easily.
* ⏭️ **Next & Previous:** Switch between tracks.
* 📃 **Playlist:** Select songs directly from the playlist.
* 🔀 **Shuffle:** Play songs in random order.
* 🔁 **Repeat:** Repeat the current song.
* ⏱️ **Progress Bar:** Track playback and seek to a specific time.
* 🔊 **Volume Control:** Adjust the music volume.
* ❤️ **Favorites:** Mark the currently selected song as a favorite.
* 📱 **Responsive Design:** Works on desktop, tablet and mobile.
* 🌙 **Modern UI:** A dark-themed interface with a purple accent.

## 🛠️ Technologies Used

* **HTML5** – Structure of the music player.
* **CSS3** – Styling, responsive layout and animations.
* **JavaScript** – Audio playback and interactive controls.
* **HTML Audio API** – Playing and controlling audio.

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/patantaslim0514-source/CodeAlpha_MusicPlayer.git
   ```

2. Open the project folder:

   ```bash
   cd CodeAlpha_MusicPlayer
   ```

3. Open `index.html` in your browser or use the VS Code Live Server extension.

4. Press the Play button to start listening.

**Note:** An internet connection is required for the sample audio tracks and online album artwork.
